RAM ≤ 1 ГБ/воркер, горизонтальное масштабирование (§16), без гигабайтов памяти.

## Гипотезы (по цене проверки)

### H1 — CosyVoice на CPU ❌ (проверено)
RTF 3.7–4.5: воспроизведение не успевает за генерацией. Для телефонного пути
на CPU отклонено. MPS — отдельный квест (несовместимые операторы).

### H2 — Piper ru ✅ как fallback (проверено)
RTF 0.03–0.21, русский из коробки. Качество = класс Silero. Ценность:
второй независимый движок (bulkhead) и базовая линия арены.

### H3 — Фразовый кэш ✅ (сделано, расширяемо)
Acks пререндерены. Следующий шаг: топ-30 типовых реплик (приветствие,
«Как вы себя чувствуете сегодня?», прощания, уточнения самочувствия)
пререндерить при старте → мгновенный ответ без генерации для 30–50% ходов.

### H4 — Kokoro-82M + русский G2P (проверка ~1 день, $0)
Официального русского нет. Проверка: espeak-ng ru-фонемы → 10 фраз → слушать.
Если разборчиво → кандидат на fine-tune (H6). Если нет — мимо.

### H5 — CosyVoice ONNX/OpenVINO int8 на x86 (проверка 1–2 дня, $5–10 VPS)
На x86 с AVX-512/VNNI int8-инференс даёт 2–6×. Цель: RTF ≤ 0.5.
Если да → CosyVoice становится **отдельным TTS-пулом на x86-облаке** по §16
(качество живое, масштабируется репликами). ARM-Mac для этого не годится.

### H5a — Оптимизация CosyVoice на ARM (проверено 2026-08-21, потолок найден)

| Вариант | RTF | Итог |
|---|---|---|
| fp32 базово | 3.7–5.6 | — |
| **flow steps 10→4 + JIT** | **3.33** | ✅ −40%, качество на слух ок |
| BF16 autocast (LLM) | 3.24 | ❌ шум, не ускорение |
| torch dynamic int8 (Linear) | 3.62 | ❌ нет ARM-ядер в torch CPU |
| MPS | — | ❌ несовместимые операторы |

Профиль: **LLM-стадия ~80%** времени (авторегрессионные speech-токены,
~130 мс/токен на этом CPU; для RTF ≤ 1 нужно ≤ 5 мс/токен — 26×).
Вывод: torch-уровнем ARM не лечится. Полёт = x86 с VNNI (H5) или GPU.
Оптимизированные сэмплы: `~/cosyvoice-lab/samples/cosy_fast_long.wav`.

### H6 — VeraVoice: свой голос (главный трек, 1–2 недели, $100–300 GPU-аренда)
Matcha-TTS ru (или Kokoro-ru fine-tune): датасет 5–20 ч (актёр с лицензией,
или CosyVoice-генерация + валидация ушами), обучение на арендованной GPU,
экспорт ONNX. Ожидание: RTF ~0.1–0.3 CPU, RAM 200–400 МБ, естественность
выше Silero, голос и лицензия — наши. Это и есть ответ на задачу
«естественность CosyVoice на скорости Silero».

### H7 — Масштабирование победителя
Любой бэкенд с RTF ≤ 0.3 кладётся в TTS-пул §16: 1 ядро ≈ 3 потока аудио →
500 concurrent ≈ 20–50 ядер TTS-пула, реплики за admission control'ом
(уже есть: `MOSS_MAX_CONCURRENT_CALLS`, 503 capacity).

## Гейты продвижения нового бэкенда

- **G1 скорость:** RTF ≤ 0.5 на целевом CPU (arena-скриптом).
- **G2 память:** RAM ≤ 1 ГБ/воркер.
- **G3 уши:** слепое прослушивание 100 фраз (greeting/empathy/safety/числа/
  имена/даты): naturalness и elder-friendly ≥ Silero + 2 (из 10) — решает
  владелец продукта.
- **G4 интеграция:** бэкенд `--model` в tts_server (интерфейс плагинный) +
  звонок 20 минут без развала + латентность первого звука не хуже +100 мс.
