# Fish Audio / Newo.ai: что проверить для IMVERA

Дата чтения официальных источников: 2026-09-30. Проверены опубликованные
документы, без оплаченных API-запросов, прослушивания демо или тестов на
телефонной речи пожилых людей. Это обзор возможностей, не рейтинг качества.

## Сравнение

| Область | Fish Audio | Newo.ai | IMVERA / решение в этом срезе |
| --- | --- | --- | --- |
| Продукт | TTS/ASR/voice cloning и Fish Agents public beta | Голосовые AI employees для бизнеса | Звонки заботы и миссии приложения |
| Управление разговором | Prompt, KB, tools; по умолчанию ответы генерирует модель платформы | После хода проверяет собранные/недостающие данные и ведёт процедуру | Типизированный Understand → единый State → планировщик → Renderer |
| Разговор прерван новой темой | История, инструменты, configurable agent | Оркестрация многошаговой работы | Жалоба прерывает custom mission; общий planner; возврат к незавершённой цели |
| Исполнение действий | Webhook/client/system tools и transfers | Обещание привязано к действию, защита от повторного выполнения | Реальные эффекты и поколения; никаких неподтверждённых медицинских обещаний |
| Разработчик | REST, Python/JS speech SDK, web/React agents SDK, custom OpenAI-compatible endpoint | Builder, visual studio, интеграции | Данные CallMission, provider DI, canonical RichUserTurn, trace причины принятия модели |
| Проверки | Next-reply, tool, simulation; LLM judge плюс детерминированные проверки | Транскрипты, записи, результаты; процедура и commitment tracking | Прямые инварианты фактов/цитат/контроля, corpus, actor regression, воспроизводимые engine replies |
| Версии/наблюдаемость | Immutable published versions, session history, post-call analysis, webhooks | Каждая беседа с summary/recording/outcome | SHA/runtime check, trace, ADR-024 proof contract; live acceptance ещё требуется |

Fish — уже не только поставщик голоса: Agents объединяет распознавание,
turn-taking, синтез, инструменты и телефон. Официальная страница указывает
public beta и возможность изменения API. Custom LLM получает полный контекст
и отвечает по streaming chat completions; это интерфейс для разговорного
backend, а не доказательство отсутствия генеративной LLM.

Newo сильна именно публично описанной оркестрацией: проверка обязательных
сведений после каждого хода, привязка обещания к результату, предотвращение
дублирования действий. «Агент за три минуты» относится к первому пробному
разговору: их же product page отдельно говорит о неделях подключения телефона
и используемых систем. Архитектурный вывод — качество определяется всей
цепочкой действий и результатов, а не разнообразием отдельных фраз.

Fish streaming TTS умеет начать воспроизведение готового текста до окончания
синтеза; для этого генеративная LLM не обязательна. Потенциальный TTS benchmark
в будущем допустим отдельно от замены владельца диалога. В этом срезе
провайдеры голоса/распознавания и лицензии не менялись.

## Измеримые цели для демонстрации

Показать реальные реплики на входах, которых нет в таблице готовых ответов:

1. Четыре сведения одним ходом: закрыть цели и не переспрашивать их.
2. «Не помню» после onset: сохранить незнание, перейти дальше без придуманной даты.
3. Отказ в составной реплике и затем goodbye: DECLINED call outcome, без ложного GREEN.
4. Жалоба посреди вопроса о покупках: уточнение жалобы, затем возврат к продуктам;
   «сегодня» заполняет время боли, а не список покупок.
5. Продукты и жалоба одним ходом: сохранить точную продуктовую клаузу и отдельный эпизод.
6. Модель ошибочно предлагает backchannel на факт/опасность: факт и контроль сохраняются;
   trace честно показывает rejected vote.

Текстовые результаты воспроизводятся `python scripts/dialogue_sdk_demo.py`.
Live превосходство над конкурентами требует общего набора аудио, русской
телефонной полосы, замеров p50/p95, качества понимания, ложных закрытий целей,
завершения задач, восстановления после перебивания и ошибок поставщиков.
Маркетинговые проценты accuracy и latency Newo/Fish сюда не переносились.

## Источники

- [Fish Audio](https://fish.audio/): продуктовые возможности и модели.
- [Канонический индекс документации](https://docs.fish.audio/llms.txt): актуальные разделы SDK/API/Agents.
- [Fish Agents overview](https://docs.fish.audio/agents/overview.md): public beta, capabilities, единый agent для console/REST/SDK.
- [Custom LLM](https://docs.fish.audio/agents/build/custom-llm.md): модель платформы по умолчанию и streaming endpoint.
- [Agent tests](https://docs.fish.audio/agents/test/agent-tests.md): text simulations/LLM judge; voice проверяется отдельно.
- [Python realtime streaming](https://docs.fish.audio/developer-guide/sdk-guide/python/websocket.md): HTTP/WebSocket streaming готового текста.
- [Newo](https://newo.ai/): продукт, каналы и заявленные метрики.
- [Newo platform](https://newo.ai/product/): procedure tracking, commitments, action deduplication, сроки интеграции.

Сертификации, лицензии конкретных весов, качество русского голоса и цифры
конкурентов не проходили независимую проверку. Обещание «конкуренты будут
бояться» не является инженерным критерием и этим обзором не подтверждается.
