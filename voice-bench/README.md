# voice-bench — Vera TTS baseline and pronunciation benchmark

Корпус: `vera_voice_500.txt` — 500 фраз, 10 категорий по 50 (приветствия,
разговорные, эмоциональные, safety, имена, отчества, города, числа/даты,
сложные ударения, длинные предложения).

Запуск (нужен qwen-venv с faster-whisper):
```
python3 bench.py silero        # полный прогон 500 фраз
python3 bench.py piper
```

Метрики на бэкенд: RTF avg/p95, RAM, round-trip WER (TTS→STT→сравнение —
автоматическая ловля проглоченных/искажённых слов; STT один и тот же для
всех бэкендов, поэтому сравнение честное). Аудио по фразам: `out/<backend>/`.
Худшие WER-фразы — на прослушивание человеком.

**Базовая линия (2026-08-21, 500 фраз, 0 ошибок):**
| Бэкенд | RTF avg | RTF p95 | round-trip WER |
|---|---|---|---|
| Silero kseniya (прод) | **0.015** | 0.016 | 0.269 |
| Piper irina-medium | 0.026 | 0.033 | 0.285 |

Гейт смены голоса: RTF ≤ 0.5 И понятность ≥ Silero И естественность заметно
выше (слепое прослушивание владельцем) — см. `docs/TTS_ARENA.md`.
